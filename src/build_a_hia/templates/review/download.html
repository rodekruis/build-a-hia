Copying into the HIA

  1. Make a fresh copy of the HIA template. Do not paste into an HIA that already has content.
  2. In Categories, Sub-Categories, Offers and Q&As, copy rows 3 and below from hia.xlsx and paste them into the same rows of the template using Paste special › Values only.
  3. In Referral Page, copy only the filled values in column B (text direction, language, last updated).
  4. Review everything for public disclosure before changing any visibility to “Show”. Hidden rows are still public.
